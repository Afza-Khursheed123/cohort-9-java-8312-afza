# Contact Management Frontend

React and Vite frontend for the Contact Management application.

## Prerequisites

- Node.js 20 or newer
- The backend running at `http://localhost:8080/api`

## Run locally

```bash
npm install
npm run dev
```

The development server is available at the URL Vite prints in the terminal (normally `http://localhost:5173`).

## Other commands

```bash
npm run build
npm run lint
```
